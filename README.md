# OpenCV PixelLab

##  Overview

**OpenCV PixelLab** is a beginner-friendly computer vision and image processing project developed using **Python** and **OpenCV**. The project focuses on understanding fundamental image processing operations such as image reading, grayscale conversion, image visualization, pixel manipulation, and image saving techniques.

This project demonstrates how OpenCV can be used to process and manipulate digital images efficiently using classical computer vision techniques without requiring machine learning models.

It is designed as a practical learning project for students and beginners who want to build a strong foundation in computer vision and image processing.

---

#  Features

-  Reads and processes digital images
-  Converts images into grayscale format
-  Displays image properties and dimensions
-  Visualizes images using Matplotlib
-  Saves processed images in different formats
-  Demonstrates pixel-level image manipulation
-  Fast and lightweight implementation using OpenCV
-  Easy to extend with advanced image processing operations

---

#  Concepts Used

This project demonstrates several important computer vision concepts:

- Image Reading and Writing
- Grayscale Image Processing
- Pixel Manipulation
- Image Visualization
- Image Properties Extraction
- Matrix Representation of Images
- Basic Image Processing Operations
